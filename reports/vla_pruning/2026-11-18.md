## A. 今日新增论文

### 1. POKE: Probe Offline, Keep Efficiently for Vision-Language-Action Models

- **作者**：Jaehyuk Lee、Yeajin Lee、SuHyun Bae、Donghun Lee。
- **原始链接**：[arXiv 摘要及版本记录](https://arxiv.org/abs/2611.21033) · [论文 HTML 全文](https://arxiv.org/html/2611.21033v1)。
- **首次公开**：2026-11-17，见 [arXiv cs.CV 当日新刊出列表](https://arxiv.org/list/cs.CV/new)；v1 提交时间为 2026-11-16 12:52:36 UTC。**发表状态**：arXiv v1 预印本；未核实到会议或期刊正式录用记录，会议及年份为“未确认”。[证据](https://arxiv.org/abs/2611.21033)。
- **分类**：**Training-based**。VLA 主干冻结，但须用机器人示范数据离线生成动作敏感度标签并训练独立 selector；推理时不训练、不反向传播。
- **核心方法（249 字）**：POKE 把视觉 token 的重要性定义为：以所属相机的均值替换该 token 后，最终动作的一阶变化幅度。作者用随机方向反向传播近似 token 的动作敏感度，在冻结 VLA 的完整计算图上离线生成标签，再训练不足 30 万参数的学生网络。推理时，学生根据视觉、语言、机器人状态和相机位置打分，先筛高分候选，再用特征距离增加多样性，于 Transformer 中段删除其余 token。离线蒸馏免去逐步反向传播，也减少已剪枝计算图偏爱旧掩码的位置；选择器仍需训练，敏感度只是实际删除损伤的近似。 [方法原文](https://arxiv.org/html/2611.21033v1)。
- **剪枝依据与实现**：以最终动作对单个视觉 token 的一阶敏感度作为监督信号；替换基准是**各相机自己的 token 均值**，避免混合视角。学生网络结合 token、语言、机器人状态、相机/空间位置给分；可直接 top-k，或在高分候选中做最大最小特征距离选择（MMDP），每相机固定分配一半预算。**位置**：视觉编码及投影之后、VLA Transformer 内部；OpenVLA-OFT 在第 4 层输入、π0.5 与 OpenVLA 在第 3 层输入删除视觉 token（层号从 0 起），非视觉 token 保留。不是编码器前剪枝，故仍需编码全部图像 patch。[方法与实现](https://arxiv.org/html/2611.21033v1)。
- **Backbone 与任务**：主实验是 OpenVLA-OFT 和 flow-based **π0.5**，LIBERO 的 Spatial、Object、Goal、Long 四套任务及 LIBERO-Plus 扰动测试；每套 LIBERO 评估 500 条 episode。两者均接收第三人称/agentview 与腕部相机的 512 个视觉 token（每视角 256）。补充实验含自回归 OpenVLA 的 LIBERO，以及 **open-pi-zero 的 π0 复现模型**在 SimplerEnv WidowX 上的测试；后者学生用 BridgeData V2 帧训练，不能视为官方 π0 实机验证。[实验设置](https://arxiv.org/html/2611.21033v1)。
- **压缩、延迟与成功率**：每次保留 32/512 token，即 **6.25%**，剪去 93.75%。POKE-MMDP 在 OpenVLA-OFT 上平均成功率 **95.15%**（未剪枝 96.70%），调用延迟 **130.1→70.4 ms**，**1.85×**；在 π0.5 上为 **90.80%**（未剪枝 96.50%），**84.7→67.4 ms**，**1.26×**。更适合 π0.5 的 64/512（12.5%）预算给出 **95.35%** 成功率、**1.22×** 加速，相对未剪枝下降 1.15 个百分点。延迟包含在线打分和选择，但按论文协议是**剪枝后的控制调用**计时，前三次预热调用未剪；π0.5 使用 CUDA graphs，硬件为 RTX A6000，因此不能直接外推到机器人整机端到端控制延迟。[成功率表](https://arxiv.org/html/2611.21033v1) · [延迟表](https://arxiv.org/html/2611.21033v1)。
- **开源代码**：论文及 arXiv 页面未给出 POKE 官方代码链接；目前记为**论文未报告**。[论文](https://arxiv.org/abs/2611.21033)。
- **相对创新**：相较 attention 或纯多样性规则，以**动作输出敏感度**蒸馏训练 selector；特别指出在已剪枝图上逐步打分会出现“旧掩码锁定”（随机掩码实验中有 59% 的选择仍落在旧掩码内，随机预期约 6%），并以完整图离线标签规避。与 APS-VLA 同属训练 selector、冻结主干，但 POKE 的监督更直接来自**最终动作的局部变化**，且显式研究双相机配额及 flow-based π0.5 的性能与延迟。[锁定证据](https://arxiv.org/html/2611.21033v1) · [主实验](https://arxiv.org/html/2611.21033v1)。

## C. 最值得关注的论文

**第 1 位：POKE**（今日主列表仅此 1 篇）。[原文](https://arxiv.org/html/2611.21033v1)。

1. **π0/π0.5 剪枝**：对 flow matching 的 π0.5，离线标签对完整去噪积分后的最终动作求敏感度，而非只看单一步速度；同时报告 π0.5 的 64/512 配置较 32/512 更接近未剪枝成功率。π0 的补充实验使用 open-pi-zero 复现模型，须与官方 π0 验证分开看。
2. **头部与腕部相机**：论文实测的是第三人称/agentview 加腕部相机，**不是头部相机**。按相机独立求均值和每视角固定 16/32 或 32/64 个名额，能避免某一视角完全失去 token；但没有验证动态跨相机预算，也未量化头部与腕部冗余。
3. **动作敏感性**：以 token 替换引起的最终动作变化训练 selector，比单看 attention 更贴近控制目标；完整图离线标签还可作为检验在线剪枝选择偏差的参考。
4. **精细操作与开销**：32/512 的 π0.5 成功率比未剪枝低 **5.70 个百分点**，不能只看 93.75% 剪枝率或 1.26× 加速。优先复现 64/512、按 LIBERO 子任务和腕部视角拆分成功率，并在目标机器人硬件上重测完整控制周期。[结果表与计时说明](https://arxiv.org/html/2611.21033v1)。

## D. 今日结论

今日出现一篇把**完整图动作敏感度离线蒸馏为轻量视觉 selector**的直接相关工作。它同时报告了双相机、flow-based π0.5、token 预算、任务成功率和真实调用延迟，值得优先复现。其局限是要训练 selector、编码器仍处理全部 patch，且极低预算下 π0.5 成功率明显下降；“头部—腕部”动态互补与真实机器人精细操作性能仍待验证。[POKE 原文](https://arxiv.org/html/2611.21033v1)。
